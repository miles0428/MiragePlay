# Language

The UI is English by default. Two more languages are bundled: Traditional
Chinese (`zh-Hant`) and Simplified Chinese (`zh-Hans`).

Switch in **Preferences → Language** (`prefs.row.language`). The strings are in
`app/Resources/Strings/terms.json`: 51 keys, each with `en`/`zh-Hant`/`zh-Hans`.

The language is not detected from the system locale — the app starts in English
until you change it.
